Design Manual

Colour Scheme

Each Gallery selects one named theme through top-level theme in site.md. Missing values use the Cebreus default: Slate surfaces, Orange brand, and Orange-to-Red gradients. Barcelona selects Mauve/Violet. The colour system extends Tailwind CSS colours with semantic tokens. Main, sidebar, agenda, filter, and editing surfaces use the active theme. The sidebar uses adjacent palette stops, darker than the main surface in light mode and lighter in dark mode.

Brand and gradient colours come from the active theme. Red remains reserved for destructive actions and error states outside the Cebreus brand gradient. Info, success, and warning states use named status tokens. Photo, lightbox, editor, and debug overlays may use fixed dark colours when their backdrop is explicitly dark. Token definitions live in src/app.css.

Font Stacks

The project currently uses the default Tailwind CSS font stacks, as no custom fonts are defined in either tailwind.config.ts or src/app.css.

  • Sans-serif: 'ui-sans-serif', 'system-ui', '-apple-system', 'BlinkMacSystemFont', "Segoe UI", 'Roboto', "Helvetica Neue", 'Arial', "Noto Sans", 'sans-serif', "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", "Noto Color Emoji"
  • Serif: 'ui-serif', 'Georgia', 'Cambria', "Times New Roman", 'Times', 'serif'
  • Monospace: 'ui-monospace', 'SFMono-Regular', 'Menlo', 'Monaco', 'Consolas', "Liberation Mono", "Courier New", 'monospace'
